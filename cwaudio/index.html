Using the Sound function

Call it from any script on the page with Run function. The first field is PLAY, PAUSE or STOP, and the second is the song name.

Run function (Sound) ("PLAY", "mysong")    start, or resume after PAUSE
Run function (Sound) ("PAUSE", "mysong")   pause, PLAY continues from here
Run function (Sound) ("STOP", "mysong")    stop and rewind
Run function (Sound) ("PLAY", "other")     switch to another imported song
How it works

Each song file loads its numbers into a shared song table when the page loads. The player starts its Voice function 50 times in the background, and each copy controls one looped copy of the 1750 Hz sine. A song stores keyframes per voice: only the moments where pitch or volume changes direction. About 60 times a second, every voice slides its Speed and Volume smoothly between its keyframes.

Variables used: {2}–{21} playback state, {898}–{900} song loading. Avoid using these numbers in your own scripts.

Troubleshooting
  • "song not found" warning: the name in Sound doesn't match the song file's name, or the song file wasn't imported.
  • Laggy or stuttering: use fewer voices or the Coarse detail setting.
  • Only one voice plays, or it sounds wrong: tell me. It means CatWeb shares local variables between background function calls.
